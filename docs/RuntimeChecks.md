# 游戏内验收

构建与独立数据测试已执行；以下项目需要在 Skyrim 中验证。记录实际 Skyrim runtime、SKSE、SOS Revived 版本，以及 `SkyWardrobe.log` 中的回调状态。不要将 DLL 编译成功当成外观测试通过。

1. **打开 / 输入恢复**：主菜单进入游戏后分别输入 `wardrobe`、`wa`、`sa`，确认控制台关闭且衣柜显示；Esc / 窗口关闭后恢复鼠标视角与移动。默认 F11 不打开；启用快捷键后测试重新绑定、禁用、再次控制台打开。Ctrl+V 粘贴中文到别名和备注；关闭再打开后检查 Ctrl / 鼠标按键不会卡住。
2. **窗口与字体**：调整大小、位置、UI 缩放和鼠标灵敏度，重新启动检查保存。中文标题与较小灰色备注清晰可见；长文本不溢出卡片，悬浮显示完整文字。
3. **目录与 ESP**：选择两个实际衣服插件并注册，检查来源 ARMO 数量、原名、ESL 本地 ID。右键编辑收藏与多个分类，切换左侧 Favorites、分类、未分类。修改插件 / 分类名称和拼音搜索词，确认搜索命中。不给服装填写手工拼音，将别名设为“黑色连衣裙”，验证 `heiselianyiqun`、`hslyq`、`lyq`、`heiselyq` 命中，`hlyq` 不命中；分类、插件别名和预设名称也检查自动拼音。修改别名并保存 / 重新加载后确认结果更新。检查日志出现 `Automatic pinyin search initialized`。
4. **别名包与搜索**：把示例的插件与 ID 换成真实记录，复制到 AliasPacks；执行 reload。`qunzi`、`qz`、`qzi` 命中“裙子”；只改收藏后别名仍来自包；用户别名覆盖包，“恢复原始数据”回到包。
5. **部件列**：将当前分类服装标记为全身 / 鞋 / 袜 / 自定义部件；设置 7 列并开启分配，大部件获得额外列，空部件隐藏。设置列数小于部件数时检查横向滚动，每个部件保有独立列。
6. **工作搭配 / 预设**：加入同槽衣服，确认只替换工作搭配冲突项。保存 A，修改工作搭配，A 出现 `*` 且已保存内容不变。覆盖、撤销、恢复、另存 B、改名、删除与重启恢复。缺失插件的预设保留并显示缺失 ID；应用拒绝部分成功。
7. **外观覆盖**：实际装备设置为“关闭”，SOS 启用，玩家穿着有明确属性的装备；应用不同工作搭配，日志依次完成 SOS 回调并回读 `__WARDROBE_RUNTIME__`，检查视觉变化而实际装备、护甲值、物品数量不变。双击应用与实时预览也检查。清除后当前实际装备显示恢复，JSON 预设保留。
8. **快速操作 / 读档**：连续切换服装，最终外观应对应最新请求；读档取消旧链，重新应用应可用。SOS 未安装或被禁用时显示明确提示，浏览、搜索和元数据编辑仍可使用。大量服装目录下分别关闭和开启实时预览，连续点选穿脱，检查界面响应；后台保存完成后显示 Saved。立即关闭面板再打开，或点选后立即重新加载 JSON，确认最后的工作搭配保留。穿脱后立即编辑元数据并显式保存，重启确认工作搭配和元数据都保留；保存失败应显示错误，修复写权限后使用“重试保存”。
9. **文件错误**：备份后故意改坏 Wardrobe.json，reload 提示错误，不清空当前数据且保存不覆盖坏文件；修复后 reload 恢复。坏 AliasPack 仅跳过该包并列出错误文件。

玩家使用 SOS 的地点 / 战斗自动换装时，该系统可能在后续事件中重新选择自己的服装。衣柜不修改 SOS 的自动换装配置；持续外观验收时关闭该项。

## 可选实际装备验收

记录 Skyrim runtime、SKSE、SOS、RaceMenu/高跟高度修复模组版本。本功能已实现原版穿戴路径，高跟高度是否恢复仍需这组游戏验收确认。

1. 旧 JSON/默认设置为关闭；只应用外观，物品栏和属性不变。切换模式并重启，检查设置保留。
2. “仅鞋子装备”：工作搭配含上衣、槽位 37 的高跟鞋、仅槽位 38 的袜子。应用后只实际穿上鞋，上衣和袜子走 SOS；比较同一双鞋在物品栏装备与衣柜应用后的高度。多槽位鞋仍应实际装备。
3. “全部装备”：实际穿上整套工作搭配，检查护甲与附魔效果。玩家已有强化/附魔服装不增加数量，实例数据保留；缺少服装只添加一件，重复应用不累计副本。
4. 开启模式时切换 A→B、移除部件、切换为仅鞋子后再应用：不再需要的衣柜实际穿戴项卸下，临时物品回收；没有被衣柜实际穿戴的原装备不主动卸下，也不恢复先前被替换项。
5. 分别清除外观和切到关闭：临时物品卸下并回收，玩家原有服装保持当前穿戴。再开启并应用，缺少项重新添加。切到关闭保留 SOS 外观；只有清除外观才清空 SOS Outfit。
6. 临时物品存在时保存并重启读档，再清除；检查能回收该存档的临时实例。切换到另一份存档或新游戏，不得处理旧世界物品。当前全局设置为关闭时，读档后也安排临时物品回收。
7. 临时物品添加后，再获得同款服装并强化/附魔，随后切换/清除；只回收记账实例。将临时物品转移到其他容器后清除，不删除容器物品，也不删除玩家后来获得的同款物品。
8. SOS 禁用、预设包含缺失 FormKey、真实穿戴槽位冲突、原版拒绝装备/卸下时：显示失败状态；SOS 失败不添加新服装。清除临时物品不依赖 SOS 启用。穿戴失败可能已完成部分实际穿戴，按状态检查并清除临时物品；不将 SOS 外观成功等同于原版穿戴成功。

## 服装组验收

在匹配的 Skyrim SE/AE + SKSE + Address Library 环境中检查：旧 JSON 载入后预设绑定迁移组；分类/插件/其他组都可编辑信息和使用。注册插件后 JSON 不应出现全量成员列表。组引用在分列视图最左侧，点击跳转；引用组中的服装不能进入随机结果。多次使用含冲突槽位的组应出现不同选择，结果槽位不重叠。创建子组后父子引用可往返，重复创建名称不冲突。快捷添加可再次点击移除，标记部件在其他组同样可见；插件组不能快捷移除。所有组内同一物品的别名、备注、搜索词和部件一致，保存/重载后保持。检查只含引用和完全空组的界面。游戏运行时版本及实际结果需在现场验收时记录。

## 快捷浮窗验收

记录 Skyrim runtime 与 SKSE 版本，执行 `wa`，确认主面板和快捷浮窗同时出现、关闭菜单后一起消失。点击空格子配置分类跳转，从“预设”或“界面设置”页点击分类图标，确认主面板立即切到衣柜和对应分类，旧搜索不阻挡结果。分别验证查看服装组、选择预设、应用预设和使用指定服装组；后两项无需额外点“应用”，沿用已有随机选衣和槽位互斥逻辑。实时预览开启时应用预设不重复请求。

右键已绑定格子修改图标和目标，测试中文 / 英文图标搜索、同名不同 ID 的目标、取消与清空。调整到 1 × 1、3 × 5 和 12 × 12，改变方格大小与 UI 缩放，确认格子始终正方形、隐藏绑定在扩大后恢复、大网格可以滚动。拖动主面板到视口左右边缘，检查浮窗仍可操作；关闭跟随后拖动浮窗并重新打开菜单。禁用浮窗后通过“界面设置”重新启用并编辑格子。

等待保存状态变为 Saved，重新加载 JSON / 重启游戏，检查尺寸和绑定保留。改名目标应自动更新悬停名称；删除分类、服装组或预设绑定组后，格子标为失效且点击不应用旧工作搭配，右键可修复。以上为待游戏内验收项；离线测试验证配置边界、序列化和隐藏绑定保留，编译不等同于游戏内交互验收。

## 元数据编辑性能验收

在大量服装目录中连续修改部件、分类、收藏及服装组归属，检查点击响应与搜索、分列、组成员显示立即更新。连续编辑期间保存状态应为 Saving，后台完成后为 Saved；关闭面板后仍应完成保存。连续穿脱与元数据编辑交替操作后立即重新加载 JSON，确认最后的工作搭配和元数据均保留；写盘失败应显示错误，恢复写权限后点击“重试保存”并检查重载结果。名称及分类搜索词修改后检查原文和拼音搜索更新。保存按钮提交后台保存，Saved 状态才表示写盘完成。

## 外部输入法验收

三个 provider 分别单独安装运行，记录 Skyrim runtime、SKSE、输入法 DLL 版本和 Windows 输入法。检查设置页和 `SkyWardrobe.log` 的 `External IME provider` 与实际安装一致。没有外部模组时英文 / Ctrl+V 应保持可用；同时安装多个已知输入法 DLL 时显示冲突，衣柜不主动申请输入法焦点。

1. SimpleIME：候选窗位置设为 Follow Cursor 或 None。搜索、别名、备注分别组词，测试空格、数字、方向键选词，Enter 确认和 Esc 取消。首次 Esc 取消组词时衣柜不能关闭，之后退出文本编辑，再按 Esc 关闭衣柜。
2. Skyrim Input Method：执行相同检查，尤其确认顶层菜单收到上屏文字而非控制台、字母拼音不同时进入输入框、组词方向键不移动编辑光标。
3. Input Method Unlocked：窗口 / 无边框模式下使用 IMM 兼容输入法测试。确认过滤后的游戏字符与退格直接进入衣柜，不打开 `SkyWardrobe Text Input` 菜单。分别用空格与数字选词；组词时退格仅删拼音，组词清空后再退格删输入框文字。切换中文 / 英文后英文正常上屏；点击非文本区域结束编辑应出现 `IME text lease released`，再次点击输入框只申请一次。Esc 在组词时取消组词，之后退出文本编辑，再次按下关闭衣柜；长按退出编辑的 Esc 不应顺带关闭。一次提交超过五字的整句，记录实际版本是否完整；发布版 2.0 与本次读取的 2.1.0 main 行为需分别记录。候选窗不可见暂不作为本次修复的验收项。
4. 每种 provider 都输入“裙裙”和中英文标点，检查无去重、无重复、无乱码。Ctrl+V 中文长句只粘贴一次；菜单型输入法自身 Unicode 粘贴分别启用 / 禁用，回退仍应工作。
5. 组词时切换输入框、点窗口关闭、Alt+Tab、切控制台 / 原生菜单、新建或读档，再次打开检查旧字符不会进入新字段，Ctrl / Shift / Alt 不会卡住，候选窗退出且原生文本输入恢复。
6. 调整 UI 缩放后检查候选窗可用；拖动窗口、卡片点击和鼠标命中位置不变，键盘输入不触发玩家移动或攻击。打开 SimpleIME 工具窗口时检查菜单接管和恢复。

2026-10-05，用户在 Skyrim 1.5.97 / IMU 2.1.0 环境报告初版输入异常，修正后确认问题已修复。该反馈针对 IMU 报告的问题；以上完整矩阵、另外两个 provider、候选窗及跨输入法表现没有逐项验收记录。离线逻辑测试与编译成功只验证编码、路由策略和源代码构建。过程及完整输入流程见 [ImGui 中文输入完整报告](reports/imgui-chinese-input-retrospective.md)。
