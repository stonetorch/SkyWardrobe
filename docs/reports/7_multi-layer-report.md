# 多层服装覆盖实现报告

日期：2026-10-14。对应设计：[7_multi-layer.md](../backlog/7_multi-layer.md)。

## 实现结果

已接入三层外观合成：角色实际装备先经过槽位隐藏过滤，后备搭配覆盖其上，工作搭配具有最高优先级。手动应用、实时预览和逐角色自动换装均传入同一套角色分层配置。原版装备变化通过现有每0.5秒的角色采样合并刷新，复用已选定搭配，不推进自动换装随机／顺序进度。

应用服装组只替换工作层；后备搭配允许独立编辑或通过“设为后备搭配”选取一次结果。跨层保留冲突装备，合成时决定是否显示；同层加入仍替换槽位冲突项。预设保存／覆盖仅管理工作层，后备与隐藏规则是角色长期配置。清除外观退出全部覆盖，保留各层配置。

### 用户操作

- 中间服装卡片左键语义保持现有行为：单击加入工作搭配，重复点击保持选中；双击应用。
- 右键菜单新增“添加到后备搭配”，只添加，不删除工作层同件装备。
- 工作条目向下按钮移到后备，后备条目向上按钮移到工作。发送采用移动语义，目标已有同件装备则去重，目标层槽位冲突项被替换。两个层的列表仍支持独立移除。
- 后备可关闭，关闭时仍可编辑，编辑不自动开启。一次发送使用现有批处理，只保存并提交最终预览一次。
- 原版区可开启穿透、逐件切换隐藏、查看透出／覆盖／隐藏／临时状态。全部位置弹窗列出30–61槽位及对应实际装备，常见位置附中文名称，允许配置当前空位置。
- 最终外观与来源位于“更多”，展示工作／后备／原版来源、合成状态和覆盖装备名称。该视图是合成预览，不是引擎实际节点显示的证明。

### 右侧布局

右侧保留工作、后备、原版三个入口，标题显示件数或透出／隐藏数量。公共操作区保留预览、应用、实际装备模式；预设覆盖／恢复／撤销、清除和最终预览进入“更多”。

正常高度按内容分配空间：短列表只使用需要高度，长列表按工作层优先权重分配剩余空间。计算包含三个标题、子列表之间的 ImGui 间距及字体行高。三个列表独立滚动，右侧父区域不叠加滚动。

剩余层区域低于12行时进入紧凑布局，一次展开一层；超过13行恢复原有展开状态。切换有一行滞回，不由条目数量触发。当前展开层只控制布局，不改变左键目标。移动后不强制展开目标层。长名称裁切并提供完整名称悬停提示。

窗口最小高度按19行、最小宽度按40个字体单位计算，并受当前 viewport 限制；低于可用显示区域的极端环境仍需游戏内检查。紧凑状态和展开状态是本次会话内布局状态，未增加新的跨重启布局配置。

## 数据、SOS 与实际装备

角色数据新增 `backupItems`、`backupEnabled`、`originalEnabled`、`hiddenSlots` 和 `appearanceActive`。后备来源组记录为可选 `backupGroup`。JSON 验证检查字段类型和32位槽位掩码范围，后备 FormKey 通过现有稳定键规范化；角色 co-save 恢复分层配置。

旧配置迁移为启用但内容为空的后备搭配，原版穿透默认关闭，隐藏掩码为零，保留原工作列表。已有预设不写入后备或原版合成内容。

`MultiLayer.h` 的纯合成逻辑从高层向下选择整件装备。任意槽位冲突排除整件低层装备，原版任意槽位命中 filter 隐藏整件装备；原版 filter 不作用于工作或后备装备。各来源保留结果行和覆盖原因，零槽位同件装备也去重。

SOS backend 在游戏线程解析捕获角色的装备，合成最终外观列表，再写入独立运行时 Outfit。每次设置先重置槽位策略，再明确指定整体 `XXOO`，并将默认盾牌单槽位策略也改为 `XXOO`，避免 SOS 自行透出已过滤的原版项。继续使用原有启用检查、角色版本取消、串行回调和选中 Outfit 回读。

实际装备候选只来自最终选中的工作与后备项，原版透出项不重新装备。读取实际装备时使用现有唯一实例记账识别衣柜临时穿戴实例，并排除其底层透出；玩家原有实例保持真实装备语义。应用前装备快照与下一轮采样比较，可补上实际穿戴造成的底层变化。附近人物列表只读取基础状态，装备列表仅采样已管理角色。

加载／卸载重置 backend 分层监测。重新可用时按角色记录恢复已启用的手动覆盖；自动模式继续使用已有保存结果与条件规则。原版变化刷新采用 backend 的已应用搭配，不重新选取服装组。采样与请求合并不替代游戏内事件和外观验收。

## 游戏内待验收

本次未启动 Skyrim，因此下面项目尚未验证。验收时记录 Skyrim runtime、SKSE、SOS 与 RaceMenu／高跟相关模组版本。

1. 玩家和至少一个已管理 NPC 分别配置后备与 filter，切换角色，检查列表、预设及在途应用不串角色。
2. 工作层仅有衣服，后备有假发和鞋子，原版有护手；确认三层最终来源与实际画面一致。工作层加入／移除鞋子，确认后备鞋子透出，再移除后备鞋子检查原版透出。
3. 测试头盔与假发、多槽位连体服、盾牌；确认隐藏任一位置会隐藏整件原版装备，并且 SOS 不额外透出隐藏项。
4. 用物品栏更换真实装备，确认约0.5秒采样后刷新，自动候选和后备选取不推进。暂停／角色3D卸载后恢复，检查延迟更新及请求取消。
5. 测试两个发送方向、右键添加、目标层已有同件和槽位冲突情况，检查一次操作后的列表、持久化及预览。
6. 在不同窗口尺寸和 UI 缩放下操作三个标题、列表滚轮、长名称、完整位置弹窗和“更多”；特别检查窄宽度、自动状态提示和紧凑切换边界。
7. 用“仅鞋子”和“全部装备”测试后备高跟鞋、已有物品和临时实例，确认移除后不会从底层再次透出，实际穿戴事件不循环触发刷新；高跟高度需要与物品栏装备对比。
8. 清除外观后检查全部覆盖退出但配置保留，保存／读档后检查关闭状态和已启用覆盖恢复。原生发型与装备式假发分别验证。
