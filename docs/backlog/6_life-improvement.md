# 衣柜操作与逐角色自动换装

## 已确定的设计

### 1. 服装组目录与排序

- 新增“服装组目录”（简称目录），只组织导航条目，不收纳服装、不参与穿搭生成。目录单层，服装组只能归属一个目录，未归属放在“未整理”。引用关系保持原义，仅用于导航。
- 侧栏搜索、全部服装、收藏、未分类、工作搭配固定在顶部；下面分类服装组、普通服装组、注册模组共用一个滚动区域。分区与目录标题左对齐，成员只缩进一级，不嵌套目录。
- 分区顺序：分类服装组、服装组、已注册模组。目录及特殊分区支持折叠并保存状态；搜索临时展开匹配内容，清空恢复折叠状态。
- 分类服装组可在本区排序；普通服装组可排序、跨目录移动；目录可排序。
- 注册模组在底部分区保持内置排序，不允许单项排序；可以移动到普通服装组分区及目录，此时可排序。移动只改变导航位置，仍绑定插件来源，禁止手工改变成员，不重复显示；支持移回底部。
- 提供拖动插入线、折叠目录悬停展开、上下边缘自动滚动；大量条目使用“移动到…”选择目标目录、开头/末尾/第 N 位/指定条目前后。位置基于完整列表而非搜索结果。

### 2. 角色管理

- 新增“角色管理”Tab，集中添加注视人物、选择附近人物添加、移除管理。打开面板前记录准星目标，筛选人物 Actor，排除动物与怪物，重复添加定位已有条目。
- 玩家固定第一且不可移除。主衣柜右侧栏最上方提供当前角色选择器，位于搭配名称与公共操作之前；玩家第一，添加后自动切换；切换角色本身不应用搭配。
- 按角色引用而非 NPC 基础类型识别；工作搭配、修改基线、预设、自动状态、实际装备模式与临时物品记账逐角色隔离。资源、别名、分类和服装组全局共享。
- 每个角色独立运行时 SOS Outfit；异步请求捕获具体角色，不能因切换编辑对象而串角色。
- 移除管理停止自动换装、清理本插件接管并恢复原 SOS 自动切换设置，保留配置供重新添加；移除当前角色后切回玩家。

### 3. 实时预览

- 默认开启并保存用户设置。编辑当前角色工作搭配立即应用，关闭面板保留；切换角色不自动应用。
- 同角色连续请求合并，不丢其他角色请求。手动编辑暂缓该角色自动换装，提供“恢复自动”；下一次有效条件切换恢复，关闭面板不覆盖手动结果。
- 编辑工作搭配与自动应用结果分离。

### 4. 逐角色预设

- 一个预设是某角色的一整套条件规则，角色可有多个预设，同时启用一个。
- 优先级：战斗、地下城、城市、城镇、默认。按角色自身状态和地点关键词（包含父地点）判断。
- 每个条件支持启用及单个、随机、固定顺序候选服装组。随机避免连续同组，顺序循环，成功应用才推进，每角色每条件独立进度。
- 先选组，再沿用组内随机不冲突搭配；引用不递归收集。候选顺序独立于侧栏，支持拖动及精确移动。
- 同一状态不重复换装；未配置回退其他命中状态及默认；全部不可用保留当前外观。退出战斗恢复之前结果，读档/重新加载恢复结果，不重新抽取或推进。
- 开启自动时记录并关闭该角色 SOS 地点自动切换，退出接管恢复原值；缺失 SOS 时仍禁止 VM 调用。
- 旧预设迁移为玩家预设的默认条件，自动初始关闭，保留服装组与用户数据。

### 5. 搜索结果批量快捷操作

- “选取全部结果”“取消选取全部结果”仅在快捷操作活跃时显示，与“结束快捷操作”位于同一行。作用于当前视图和搜索筛选后的全部服装，包括滚动区域外的结果，排除引用条目。
- 快捷添加和移除模式中，选取全部向本次操作的目标组追加成员，取消选取全部从目标组移除成员；快捷移除的目标仍为当前服装组。快捷标记部件批量设置，取消仅清除匹配目标部件的用户标记并恢复自动识别。
- 注册模组不允许改成员。批量操作不修改工作搭配，组成员全部保留。
- 操作以点击瞬间结果快照执行，只保存一次，实时预览只提交最终结果一次。

## 界面与语义修正（2026-10-14）

- 旧版错误地把“选取全部结果／取消选取全部结果”理解为普通浏览时也可使用的工作搭配批量加入／移除入口。正确含义是快捷操作期间对目标组成员或部件标记执行批量追加与移除；普通浏览不显示这两个按钮。
- 两个批量按钮移至快捷操作状态行，与“结束快捷操作”同行；当前角色选择器移至右侧栏最上方。
- 中间主面板的“编辑服装组信息、使用服装组、设为后备搭配、创建子服装组、快捷操作”五个按钮同行排列，去除“设为后备搭配”前的显式换行；现有实现没有自动换行逻辑，不新增。
- 本次修正已通过 C++ 编译与 DLL 链接，`git diff --check` 通过；提权 `scripts/Build-Debug.ps1` 在后续自动复制 DLL 时因 `Permission denied` 返回1。未执行游戏内界面验收。
