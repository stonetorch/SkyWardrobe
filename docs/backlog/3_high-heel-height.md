# 问题

使用模组穿上的高跟鞋，没有被 高跟鞋高度修复 模组识别，导致高跟陷到地面里。
在游戏物品栏装备的高跟鞋能够被正确识别。

# 建议修复方案

查看 Skyrim Outfit System Revived 是否对于这种情况有处理方案，检查当前我们的实现是否与 SOS 的方案一致。

如果它也没修，那么停下来，我们也不修这个问题。

# 后续诊断与方案（2026-10-06）

用户已完成 `ApplyArmorAddon` 入口日志诊断并移除诊断代码，确认 SOS 本身也无法解决当前高跟高度问题。改用可选实际装备路径：SOS 继续负责外观，同时通过原版装备管理器让玩家真实穿上目标服装。

实现三种全局模式：“关闭”（默认）、“仅鞋子装备”（原版脚部槽位 37）、“全部装备”。启用模式在下次应用时生效，SOS 外观回读成功后才实际穿戴；双击、应用预设与实时预览共用该路径。

经用户确认，缺少的服装自动添加一件；切换搭配时回收不再需要的临时物品。清除外观或关闭实际装备时，卸下并回收临时物品，玩家原有物品保留当前穿戴，不恢复先前装备。临时实例按原版唯一标识定位，记录随 SKSE co-save 保存。

状态：实际装备兼容路径已实现；高跟高度恢复及穿戴/回收行为仍需按 `docs/RuntimeChecks.md` 的“可选实际装备验收”在游戏中确认。
